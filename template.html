安全防護 Security

  • 本機處理（Client-side processing）
    轉檔程式全部內嵌在頁面裡，不需要伺服器
  • 封鎖所有對外連線（Network isolation）
    內容安全政策 CSP connect-src 'none'
  • 不依賴外部 CDN（No third-party scripts）
    避免供應鏈攻擊（Supply-chain attack）
  • 不儲存任何資料（No storage）
    不使用 Cookie / localStorage，離開頁面即清除
  • 結果只當純文字顯示（XSS-safe output）
    文件中的 HTML／腳本不會被執行
  • PDF 安全模式（Hardened PDF parsing）
    停用 eval、外部字型、XFA 表單
  • 防壓縮炸彈（Zip-bomb guard）
    限制解壓縮體積、比例與項目數
  • 移除網址轉檔（No URL fetching）
    原網站此功能需經伺服器代理，本版不提供

使用須知與限制
  • 處理病歷、個資（PII / PHI）等機密文件時，建議把本頁存成 HTML 檔，拔掉網路後直接用瀏覽器開啟使用，效果相同。
  • PDF 只擷取文字層（Text layer）；掃描影像型 PDF 需另做光學字元辨識（OCR），本工具不會把檔案送出做 OCR。
  • PDF 的標題、段落是依字級與行距推估，複雜版面（多欄、表格）可能需要手動整理。
  • 不支援舊版 .doc / .xls / .ppt 與加密（密碼保護）檔案，請先另存為新版格式。
  • CSV／TXT 會自動判斷 UTF-8 或 Big5 編碼。XLSX 的日期儲存格會轉為 YYYY-MM-DD。
  • 轉換引擎：pdf.js 4.10（Mozilla）、mammoth（DOCX）、JSZip、Turndown；XLSX / PPTX / EPUB / CSV 為自行撰寫的解析器（不使用有已知漏洞的舊版 SheetJS）。
